AI calls: ~150 calls × 2 min × ~$0.13 ≈ $39, plus a caller number (~$10/month). Automation: n8n self-hosted ~$5–10/month or Make/n8n cloud ~$10–25. ActiveCampaign stays on your current plan.

How it works

  1. WhatsApp: Meta's coexistence lets one number run on the Cloud API and in the WhatsApp Business app at the same time, so each setter keeps chatting from the app while the automation sends templates from that same number. It is onboarded through a coexistence-capable provider (e.g. 360dialog or YCloud); one number can only be connected to one provider.
  2. AI calls: Retell AI (or Vapi) triggered by an ActiveCampaign webhook. The post-call webhook returns outcome, summary and next step, which are written back to the contact so the team sees what happened.
  3. Glue: n8n (self-hosted or cloud) or Make handles the webhooks between ActiveCampaign, the WhatsApp provider and the voice agent. No custom app to maintain.
  4. Stop rules live in ActiveCampaign goals and tags: replied, booked, or opted out ends the sequence on every channel.

What's left to finish

  • Before building: run coexistence onboarding on one setter's number to confirm the country, number type and provider all work with the app still in use.
  • Confirm your ActiveCampaign plan exposes webhooks and custom fields for the write-back.
  • Then build on test leads end to end, and record a short walkthrough for your team.
