How it works

  1. Reads the category list from the home page, then walks every page of each category.
  2. Extracts title, price, star rating, stock and product URL for each book.
  3. Compares prices with the previous run and writes the change into a price_change column.
python scrape.py books.csv        # full run
python scrape.py sample.csv 3     # 3 books per category
