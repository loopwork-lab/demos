How it works

  1. Sends the batch of emails to Claude with a strict JSON schema, so every result has the same fields and valid values.
  2. Business rules live in the prompt: what counts as urgent, which category each request belongs to, how replies should sound.
  3. Writes one row per email to CSV; the same rows can go to Google Sheets, a helpdesk, or Slack.
python triage.py emails.json triage.csv
