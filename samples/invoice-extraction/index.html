How it works

  1. Pulls the text out of each PDF, then asks Claude for a strict JSON schema: vendor, number, date, currency, terms, totals and every line item.
  2. Normalizes what varies between suppliers: date formats, currency symbols, and payment terms in other languages ('30 jours' becomes 'Net 30').
  3. Re-adds the line items and the tax in code and flags any invoice where the numbers don't agree, so nothing wrong slips into your books silently.
  4. Writes an Excel file with an Invoices sheet and a Line items sheet.
